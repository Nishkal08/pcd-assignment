Phase 1 — Lexical Analysis

Scans raw SQL source characters into a typed Token Stream via Regular Expression matching & DFA state transitions. Identifies keywords, identifiers, literals, operators, and punctuation.

Phase 2 — Syntax Analysis (Recursive Descent Parser)

Validates the token stream against the SQL Context-Free Grammar using recursive descent with precedence climbing. Produces a hierarchical Abstract Syntax Tree (AST).
